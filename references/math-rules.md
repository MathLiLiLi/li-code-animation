# 数学口径清单

这一份是全片唯一会"讲错"的地方。视觉再漂亮，口径错了就是教学事故。**逐条对照，不是参考。**

## 一、七条硬约束

| # | 约束 | 正确 | 错误（真实踩过） |
|---|---|---|---|
| 1 | 只推符号，不代数字 | 矩形面积 = `\|k\|`，三角形 = `½\|k\|` | 算出"4"并写进字幕，学生记的是数字不是结论 |
| 2 | 分数用水平分数线 | `½\|k\|` 上下排 | `1/2 \|k\|`、`|k|/2` |
| 3 | 三角形符号作右下角标 | `S` 右下角一个 `△` | `S△ = ...` 平排，读起来像乘积 |
| 4 | 称"公共点" | "图象与 x 轴的公共点" | "交点"（在讲图象与坐标轴时） |
| 5 | 负数情形固定表述 | "k<0 时，二四象限亦是如此" | "k<0 时也成立"（信息量太低） |
| 6 | 一词到底 | 全片只叫"矩形"或只叫"长方形" | 前两镜叫矩形，第五镜叫长方形 |
| 7 | 依据先于结论 | 先画矩形、再写"面积等于 k 的绝对值" | 结论卡先出，后面补证据 |

## 二、y=k/x 这类反比例题的完整口径

讲"k 的几何意义"时，按这个顺序推，不跳步：

1. **先给最简单的**：取第一象限一支，点 `P(x, 1/x)`（只写符号关系，不代具体值）。
2. **向两轴作垂线**：得矩形，宽 `x`、高 `y`，面积 `xy`。
3. **代入函数关系**：`xy = k`，所以面积 `= |k|`。**这里必须提绝对值**，否则 k<0 时就矛盾。
4. **三角形**：对角线分出的直角三角形，面积是矩形的一半，`½|k|`。
5. **推广到其它象限**：k<0 时图象在二四象限，矩形面积仍是 `|k|`，表述固定为"k<0 时，二四象限亦是如此"。
6. **纠错**：最常见的错是把"矩形面积"当成"k"，丢绝对值；第二常见的是把三角形的面积写成 `|k|`。
7. **收尾**：换一个坐标尺度（原点移动、比例尺缩小）再复述一次结论，证明它与坐标位置无关。

## 三、公式排版的具体做法

分数不能用文字拼，必须三元素：

```html
<span class="frac">
  <span class="n">1</span>
  <span class="d">2</span>
</span>
```

```css
.frac{display:inline-flex;flex-direction:column;align-items:center;vertical-align:-0.18em;margin:0 .12em;}
.frac .n{padding:0 .2em;}
.frac .d{padding:0 .2em;border-top:1.5px solid currentColor;}  /* 横线由分母的上边框充当 */
```

要点：
- 横线是**分母的上边框**，不要单独插一个 `<hr>` 或 `border-bottom` 元素，多一个元素就多一次对齐误差。
- `vertical-align` 负值让分数线与文字基线对齐，深色版常用 `-0.18em`～`-0.24em`。
- 绝对值竖线用真字符 `|` 或 `｜`，两端的间距用 `margin:0 .1em` 顶开，否则会贴字。

下标：

```css
.sub{font-size:.52em; vertical-align:-0.24em;}
```

## 四、字幕文案的写法

- 一句一个意思，**不超过 22 个字**；超了拆两句，各给一个动作。
- 数学符号用真字符，不用图片；`×`、`≤`、`≠`、`△`、`½` 都直接写。
- 结论句要能被单独截图看懂（学生暂停时看到的那一帧就是笔记）。
- 不用"我们来看一下""接下来"这类过渡语填时间——画面本身在动，不需要话术。

## 五、交付时请老师复核的三处

每次都写进交付说明，不要省：

1. **符号**：绝对值、下标位置、分数线是否对。
2. **术语**：是否与本地区教材一致（"图象"vs"图像"、"公共点"vs"交点"）。
3. **边界**：结论的适用范围有没有说过头（例如是否只对 k≠0 成立）。

## 六、常见"看起来对但其实错"的说法

| 说法 | 问题 | 改法 |
|---|---|---|
| "面积就是 k" | 丢绝对值 | "面积是 k 的绝对值" |
| "三角形面积是 k 的一半" | k<0 时符号错 | "是 k 的绝对值的一半" |
| "k 越大面积越大" | 应为"\|k\| 越大" | "\|k\| 越大，面积越大" |
| "图象不经过原点所以..." | 因果牵强 | 直接说"图象与坐标轴无公共点" |
| 用"反比例函数经过第一象限" | 函数不过象限，图象才过 | "图象位于第一、三象限" |
